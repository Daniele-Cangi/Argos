# No execution rule

Applies to the entire repository through M4.

Do not create wallet, signing, balance, allowance, order, cancellation, authenticated CLOB user-channel, private-key, mnemonic, or position-management code. Public read adapters may expose only market metadata and market-data operations.

A filename, class, test fixture, TODO, or placeholder implying future execution is also out of scope. Keep future execution discussion in owner-gate documentation only.
